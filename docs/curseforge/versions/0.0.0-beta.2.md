<h2>v0.0.0-beta.2 - Licensing</h2>

<p>Licensing-only release for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21). No functional change &mdash; the connection behaviour is identical to <code>0.0.0-beta.1</code>.</p>

<h3>Change</h3>
<ul>
<li><strong>License</strong>: Better Connections is now released under <strong>AGPL-3.0-only</strong>, matching the upstream <a href="https://modrinth.com/mod/betterwalls">BetterWalls</a> license as published on Modrinth and CurseForge. A NeoForge port is a derivative work and must carry the same license.</li>
<li>The jar now ships the full licence text and attribution at <code>META-INF/LICENSE</code> and <code>META-INF/NOTICE</code>; the mod metadata declares <code>license = "AGPL-3.0-only"</code>.</li>
<li>Complete corresponding source: <a href="https://gitlab.com/stalking-dragons/minecraft/better-connections">gitlab.com/stalking-dragons/minecraft/better-connections</a>.</li>
</ul>
