<h2>v0.0.0-beta.1 — Initial beta release</h2>

<h3>Feature</h3>
<ul>
<li>Port of <strong>BetterWalls</strong> from Fabric to NeoForge 26.1.2</li>
<li>Fences connect to walls, fences, iron bars, and wall signs</li>
<li>Iron bars connect to fences, fence gates, and wall signs</li>
<li>Walls connect to fences and wall signs</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>FenceBlockMixin</code> — extends fence connection logic</li>
<li><code>PaneBlockMixin</code> — extends iron bar connection logic</li>
<li><code>WallBlockMixin</code> — extends wall connection logic</li>
</ul>
