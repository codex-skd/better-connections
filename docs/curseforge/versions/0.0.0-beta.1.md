<h2>v0.0.0-beta.1 — Initial 1.21.1 beta release</h2>

<h3>Feature</h3>
<ul>
<li>Port to Minecraft 1.21.1 / NeoForge 21.1.249 (ported from the 26.2 branch, v1.1.0)</li>
<li>Fences connect to walls, fences, iron bars, and wall signs</li>
<li>Iron bars connect to fences, fence gates, and wall signs</li>
<li>Walls connect to fences and wall signs</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>FenceBlockMixin</code> — extends fence connection logic (no logic changes)</li>
<li><code>PaneBlockMixin</code> — extends iron bar connection logic (no logic changes)</li>
<li><code>WallBlockMixin</code> — extends wall connection logic (no logic changes)</li>
<li>Build targets Java 21; Parchment mappings 1.21.1 / 2024.11.17</li>
<li>Added <code>modLoader</code> / <code>loaderVersion</code> to the mod metadata template (required by FML on 1.21.1)</li>
<li>Mixin config no longer declares a refmap (NeoForge 1.21.1 applies mixins with official names)</li>
</ul>
