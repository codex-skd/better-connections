# Better Connections

Connects Fences, Walls, and Iron Bars together seamlessly.

## Features

- Fences connect to walls, fences, iron bars, and wall signs
- Iron bars connect to fences, fence gates, and wall signs
- Walls connect to fences and wall signs

## Requirements

- Minecraft 26.2
- NeoForge 26.2.0.32-beta+

## Installation

1. Download the JAR
2. Place it in your `mods` folder
3. Launch the game
